# Installation

## Requirements

| Requirement | Minimum |
|---|---|
| PHP | 8.2+ |
| WordPress | 6.4+ |
| Composer | 2.x |

---

## Install FieldForge Core (Free)

**Via Composer:**

```bash
composer require fieldforge/fieldforge
```

**Via WordPress.org:** Search for "FieldForge" in **Plugins → Add New**.

---

## Install FieldForge Pro

1. Purchase at **fieldforge.io/pricing**
2. Download `fieldforge-pro.zip` from your account area
3. In WordPress: **Plugins → Add New → Upload Plugin**
4. Upload the zip and click **Activate**
5. Enter your license key under **FieldForge → Pro License**

---

## Load your schemas

After activation, load your field schemas from `functions.php`:

```php
add_action('init', function () {
    fieldforge_load_schemas(get_template_directory() . '/fieldforge/');
}, 5);
```

Any `.php` file inside that directory is auto-loaded. Each file should register one or more field groups.

---

## Verify the installation

Navigate to **FieldForge → Schema Inspector** in the WP admin. If your groups appear there, the plugin is working correctly.
