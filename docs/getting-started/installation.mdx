# Installation

## Requirements

| Requirement | Minimum |
|---|---|
| PHP | 8.2+ |
| WordPress | 6.5+ |
| Composer | 2.x |

---

## Install CtrlField

CtrlField is a single plugin. Free and Pro are the same install — a Pro license unlocks the Pro features.

**Via zip** (no code): download `ctrlfield.zip` from [ctrlcheese.de](https://ctrlcheese.de), then **Plugins → Add New → Upload Plugin**. Everything it needs is inside.

**Via Composer:**

```bash
composer require ctrlcheese/ctrlfield
```

The plugin is installed into your plugins folder (with `composer/installers`) and loads through your project's autoloader. No build step: the admin assets ship with the package.

Nothing to configure for security either: field groups made in the admin are saved as files that print nothing when opened in a browser, on any web server.

---

## Unlock Pro

1. Purchase a license at [ctrlcheese.de](https://ctrlcheese.de)
2. Enter your license key under **CtrlField → Pro License**

No second plugin to install: flexible content, relational fields and the integrations switch on as soon as the license is valid.

---

## Load your schemas

After activation, load your field schemas from `functions.php`:

```php
add_action('init', function () {
    ctrlfield_load_schemas(get_template_directory() . '/ctrlfield/');
}, 5);
```

Any `.php` file inside that directory is auto-loaded. Each file should register one or more field groups.

---

## Verify the installation

Navigate to **CtrlField → Schema Inspector** in the WP admin. If your groups appear there, the plugin is working correctly.
