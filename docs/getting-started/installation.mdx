# Installation

## Requirements

| Requirement | Minimum |
|---|---|
| PHP | 8.2+ |
| WordPress | 6.5+ |
| Composer | 2.x |

---

## Install CtrlField

CtrlField is a single plugin. Free and Pro are the same install — a Pro license unlocks the Pro features.

**Via Composer:**

```bash
composer require ctrlcheese/ctrlfield
```

**Via zip:** download `ctrlfield.zip` from [ctrlcheese.de](https://ctrlcheese.de), then **Plugins → Add New → Upload Plugin**.

---

## Unlock Pro

1. Purchase a license at [ctrlcheese.de](https://ctrlcheese.de)
2. Enter your license key under **CtrlField → Pro License**

No second plugin to install: flexible content, relational fields, the Visual Builder and the integrations switch on as soon as the license is valid.

---

## Load your schemas

After activation, load your field schemas from `functions.php`:

```php
add_action('init', function () {
    ctrlfield_load_schemas(get_template_directory() . '/ctrlfield/');
}, 5);
```

Any `.php` file inside that directory is auto-loaded. Each file should register one or more field groups.

---

## Verify the installation

Navigate to **CtrlField → Schema Inspector** in the WP admin. If your groups appear there, the plugin is working correctly.
