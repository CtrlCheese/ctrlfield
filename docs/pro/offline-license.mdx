# Offline License

An offline license is a JWT token that validates entirely on-device — no API call to LemonSqueezy, no internet required. Useful for air-gapped environments or sites that must work without external connectivity.

---

## Setup

Define the constant in `wp-config.php`:

```php
define('CTRLFIELD_OFFLINE_TOKEN', 'your-jwt-token-here');
```

CtrlField detects this constant at boot and skips the LemonSqueezy validation flow. The license settings page shows **"Active (Offline)"**.

---

## Obtaining an offline token

Contact support at ctrlcheese.de/support with your purchase email. Offline tokens are issued on request to Pro subscribers.

Tokens are RSA-signed JWTs and cannot be forged. Each token encodes:

- `domain` — the site URL the token is valid for
- `exp` — expiration timestamp (annual renewal required)
- `tier` — `'personal'` or `'agency'`

---

## Token validation

When `CTRLFIELD_OFFLINE_TOKEN` is defined:

1. CtrlField decodes the JWT using the bundled public key
2. Verifies the `domain` claim matches `home_url()`
3. Checks the `exp` claim has not passed
4. Sets the tier from the `tier` claim

If validation fails, Pro features are disabled and the settings page shows the specific error (expired, wrong domain, tampered signature).

---

## Staging bypass

Staging environments (`localhost`, `*.local`, `*.staging`, etc.) bypass both LemonSqueezy and offline validation entirely. Pro features are always active on staging, no token required.
