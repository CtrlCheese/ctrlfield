# Elementor Integration

*(CtrlField Pro)*

Exposes CtrlField field values as Elementor Dynamic Tags, making them available in Elementor's text, image, URL, and other controls.

---

## Requirements

- Elementor 3.x or Elementor Pro
- CtrlField Pro active

---

## Usage

Once active, CtrlField fields appear in Elementor's Dynamic Data menu under the **CtrlField** group.

**Text field:** Use in any Elementor text control → Dynamic → CtrlField Fields → select your field.

**Image field:** Use in Image widget → Image source → Dynamic → CtrlField Fields → select your image field.

**URL field:** Use in Button widget → Link → Dynamic → CtrlField Fields → select your URL field.

---

## Supported Elementor controls

| Elementor control type | CtrlField field types |
|---|---|
| Text | Text, Email, URL, Select, Radio, TrueFalse, Number |
| Image | Image |
| URL | URL, Link |
| Color | Color |
| Custom (raw HTML) | WYSIWYG, Code |

---

## Notes

- The Elementor integration registers dynamic tags lazily — they only boot when `class_exists('Elementor\Plugin')` is true.
- Values are read via `ctrlfield_get()` and passed directly to Elementor's rendering pipeline. `returnFormat` decorators are applied.
- Elementor's post loop (Posts widget, Archive Loop) is supported — CtrlField reads field values for the loop's current post.
