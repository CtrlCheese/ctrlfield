# Repeater

*(CtrlField Pro — as in ACF PRO)*

A repeatable group of sub-fields. Users can add, remove, and reorder rows.

---

## PHP API

```php
Field::repeater(string $key): RepeaterField  // Pro
```

### Type-specific methods

```php
->fields(array $fields): static
```
The sub-fields for each row. Accepts any `FieldDefinition` instances.

---

## Storage

Stored as a JSON array. Each element is an object with sub-field keys.

```json
{
  "team_members": [
    { "name": "Alice", "role": "Engineer" },
    { "name": "Bob",   "role": "Designer" }
  ]
}
```

---

## Example

```php
Field::repeater('team_members')
    ->label('Team Members')
    ->fields([
        Field::text('name')->label('Name')->required(),
        Field::text('role')->label('Role'),
        Field::image('photo')->label('Photo')->returnFormat('array'),
    ]),
```

---

## Template usage

```blade
@foreach(ctrlfield_get('team_members') as $member)
    <div class="member">
        @if($member['photo'])
            <img src="{{ $member['photo']['url'] }}" alt="{{ $member['photo']['alt'] }}">
        @endif
        <strong>{{ $member['name'] }}</strong>
        <span>{{ $member['role'] }}</span>
    </div>
@endforeach
```

```twig
{% for member in ctrlfield_get('team_members') %}
    <p>{{ member.name }} — {{ member.role }}</p>
{% endfor %}
```

## Nesting

Repeaters nest up to **3 levels**: a repeater inside a repeater inside a repeater. Groups in between do not count as a level, but a repeater inside them does. A fourth level throws `InvalidNestingDepthException` when the schema loads.

```php
Field::repeater('menu_sections')->fields([
    Field::text('section_name'),
    Field::repeater('dishes')->fields([          // level 2
        Field::text('dish_name'),
        Field::repeater('variants')->fields([    // level 3 — the maximum
            Field::text('variant_name'),
        ]),
    ]),
])
```

- A repeater can sit inside a Group or a Flexible Content layout.
- A Flexible Content field cannot sit inside a repeater.

---

## In the editor

- **Reorder** rows by dragging the ⋮⋮ handle, at any level. With the keyboard: focus the handle and use the arrow keys.
- **Collapse** a row to a one-line summary (its first text value); "Expand all" / "Collapse all" act on one list.
- Gallery images and relationship picks are reordered the same way.

---

## Notes

- Sub-field keys must be unique within the repeater (not globally).
