# Password

A masked text input. The value is stored as typed — it is **not** hashed, same as ACF. Use it for things like staging passwords or third-party API keys, never for user account passwords.

---

## PHP API

```php
Field::password(string $key): PasswordField
```

No type-specific methods. All common methods (`label`, `required`, `instructions`, `width`, `visibleWhen`…) apply.

---

## Storage

- `"s3cr3t <value>"` (string, unchanged — tags and spaces are kept)

---

## Example

```php
Field::password('staging_password')
    ->label('Staging password')
    ->instructions('Shared with the client for the preview site.'),
```

---

## Template usage

```php
$password = ctrlfield_get('staging_password');
```

The field is not exposed in the REST API unless you call `->showInRest()`.
