# Select

A dropdown select (single value). For several values use `Field::checkbox()`.

---

## PHP API

```php
Field::select(string $key): SelectField
```

### Type-specific methods

```php
->options(array $options): static
```
Associative array of `value => label`. Required.

---

## Storage

- `"active"` (string)

---

## Example

```php
Field::select('status')
    ->label('Status')
    ->options([
        'draft'    => 'Draft',
        'active'   => 'Active',
        'archived' => 'Archived',
    ])
    ->default('draft')
    ->setIndex(true)
    ->adminColumn(true)
    ->quickEdit(true),
```

---

## Template usage

```blade
{{ ctrlfield_get('status') }}  {{-- returns 'active' --}}
```

To display the label instead of the value, use the options array:

```blade
@php
    $options = ['draft' => 'Draft', 'active' => 'Active', 'archived' => 'Archived'];
    $value   = ctrlfield_get('status');
@endphp
{{ $options[$value] ?? $value }}
```
