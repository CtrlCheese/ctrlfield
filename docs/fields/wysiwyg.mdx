# WYSIWYG

A full WordPress TinyMCE rich-text editor.

---

## PHP API

```php
Field::wysiwyg(string $key): WysiwygField
```

### Type-specific methods

```php
->toolbar(string $toolbar): static
```
TinyMCE toolbar preset: `'full'` (default) or `'basic'`.

```php
->mediaUpload(bool $allow = true): static
```
Show the "Add Media" button. Default: `true`.

---

## Storage

Stored as an HTML string. Sanitized with `wp_kses_post()`.

---

## Example

```php
Field::wysiwyg('content')
    ->label('Content')
    ->toolbar('full')
    ->width(100),
```

---

## Template usage

Always use `{!! !!}` (Blade) or `|raw` (Twig) since the value is HTML:

```blade
{!! fieldforge_get('content') !!}
```

```twig
{{ fieldforge_get('content')|raw }}
```

```php
echo wp_kses_post(fieldforge_get('content'));
```
