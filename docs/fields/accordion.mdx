# Accordion

A UI-only collapsible section that groups related fields. Must be paired with an implicit end marker (the next Tab or end of group).

---

## PHP API

```php
Field::accordion(string $key): AccordionField
```

### Type-specific methods

```php
->open(bool $open = true): static
```
Whether the accordion starts expanded. Default: `true`.

```php
->style('stacked'|'horizontal'|'side'): static
```
How a run of consecutive accordions is shown — the first one's style applies to all of them, until an accordion end:
- `stacked` (default): cards one under the other, each opens on its own.
- `horizontal`: panels side by side; the open one widens, the others become narrow strips with a vertical title.
- `side`: the titles listed on the left, the chosen section on the right.

`horizontal` and `side` keep one section open at a time (the first with `->open()`), remembered across reloads. On small screens they stack.

---

## Storage

UI-only — never stored.

---

## Example

```php
Field::accordion('advanced_options')
    ->label('Advanced Options')
    ->open(false), // collapsed by default

    Field::select('cache_strategy')
        ->label('Cache Strategy')
        ->options(['none' => 'None', 'aggressive' => 'Aggressive']),

    Field::trueFalse('lazy_load')
        ->label('Lazy Load Images'),

// Next Tab or end of fields closes the accordion
```

---

## Notes

- Fields placed after `accordion()` and before the next `tab()` (or end of fields) are inside the accordion.
- The accordion is collapsed/expanded client-side with Alpine.js — no page reload.
