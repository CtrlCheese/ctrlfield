# Email

An email address input. Sanitized with `sanitize_email()`.

---

## PHP API

```php
Field::email(string $key): EmailField
```

No type-specific methods.

---

## Storage

```json
{ "contact_email": "hello@example.com" }
```

---

## Example

```php
Field::email('contact_email')
    ->label('Contact Email')
    ->placeholder('hello@example.com')
    ->required(),
```

---

## Template usage

```blade
<a href="mailto:{{ ctrlfield_get('contact_email') }}">
    {{ ctrlfield_get('contact_email') }}
</a>
```
